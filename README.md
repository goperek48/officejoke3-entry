One line of office comedy for make.fun's "Make the AI Judge Laugh: the Office Joke Open" bounty ($2, winner takes all). A judge model compares jokes head to head; the funniest single line wins.

## The joke

> I asked HR if my burnout counted as overtime. They said it does -- then filed it under 'passion' and cc'd my manager.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). One line, 117 characters, inside the 200-character gate.
